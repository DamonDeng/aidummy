# Dummy
基于稚晖君原理，木子晓汶PCB二次开发，论坛V2版本模型进行复刻
复刻教学视频链接：
https://www.bilibili.com/video/BV18x421Q7Td/?spm_id_from=333.788&vd_source=a98d716b1df46c01ecbcd3430a76d137


1. 目录描述
- Firmware 包括ref控制板，42，35驱动板所用源代码、ESP32的驱动源码
- Hardware 木子晓汶重新设计的ref控制板，42，35驱动板,的pcb、Gaber、Html所有文件
- Model 目前所有版本复刻dummy机械臂的3D文件
- Software 涵盖 dummy studio 、CTL-Tool、木子开发的simple-cli（待完善）
- Bom 仅为视频链接中V2模型的硬件选型，且对淘宝中出现的链接质量不给予保证
- Docs 包括DH模型参数、谐波减速器参数，PCB外观等
